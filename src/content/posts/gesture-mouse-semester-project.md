# 학기말 프로젝트: 카메라 기반 제스처 마우스

학기말 프로젝트로 웹캠 영상을 분석해 손동작으로 컴퓨터 마우스를 조작하는 프로그램을 구현했다. 대회 발표용 아이디어 설명보다 **실제 구현 구조와 개선 과정**을 중심으로 정리한다.

## 프로젝트 목표

1. 실시간 영상에서 한 손의 관절을 안정적으로 검출한다.
2. 검지 위치를 화면 전체 좌표로 변환한다.
3. 이동, 클릭, 드래그 제스처를 서로 구분한다.
4. 프레임 속도가 낮아져도 조작감이 크게 나빠지지 않게 한다.
5. 오작동 시 즉시 입력을 멈출 수 있는 안전 제스처를 제공한다.

## 개발 환경

```text
Python 3
OpenCV
MediaPipe
PyAutoGUI
NumPy
일반 USB 웹캠
```

## 모듈 구성

```text
camera.py      영상 입력과 좌우 반전
hand.py        손 랜드마크 검출
gesture.py     손가락 상태와 제스처 판정
pointer.py     좌표 변환과 커서 이벤트
main.py        전체 상태와 실행 루프 관리
```

기능을 파일별로 나눠 카메라나 제스처 규칙을 변경해도 다른 코드에 미치는 영향을 줄였다.

## 좌표 변환

MediaPipe는 좌표를 0~1 사이의 비율로 제공한다. 이를 화면 크기에 곱하면 커서 좌표를 구할 수 있다.

```python
target_x = landmark.x * screen_width
target_y = landmark.y * screen_height
```

카메라 가장자리에서는 손 검출이 불안정하므로 화면 안쪽에 마진을 둔 작동 영역을 만들고, 그 영역만 전체 화면으로 매핑했다.

## 커서 안정화

검출 좌표를 바로 사용하면 손의 미세한 떨림이 커서에 그대로 나타난다. 현재 좌표와 이전 좌표를 혼합하는 보간 방식을 적용했다.

```python
smooth_x = previous_x + (target_x - previous_x) / smoothing
smooth_y = previous_y + (target_y - previous_y) / smoothing
```

`smoothing` 값이 크면 안정적이지만 반응이 느려지고, 작으면 빠르지만 떨림이 커진다. 여러 거리에서 실험해 적절한 값을 선택했다.

## 제스처 상태 머신

단순히 손가락 거리가 기준값보다 작을 때마다 클릭하면 매 프레임 클릭이 반복된다. 이를 막기 위해 상태를 나눴다.

```text
READY
→ 손가락을 붙임
→ PRESSED: 클릭 1회 실행
→ 손가락을 유지: 추가 클릭 없음
→ 손가락을 벌림
→ READY
```

드래그는 `PRESSED` 상태가 일정 시간 이상 유지됐을 때 시작하고, 손가락이 벌어지면 종료하도록 구현했다.

## 안전 기능

- 손바닥 전체를 펴면 모든 마우스 입력을 일시 정지한다.
- 손이 검출되지 않으면 커서 위치를 유지하고 클릭 상태를 해제한다.
- 커서 좌표를 화면 경계 안으로 제한한다.
- 프로그램 종료 단축키를 별도로 제공한다.

## 테스트 결과와 한계

밝은 실내에서는 한 손의 이동과 클릭이 안정적으로 동작했다. 반면 역광, 손이 얼굴과 겹치는 상황, 카메라에서 너무 먼 상황에서는 검출 정확도가 떨어졌다. 장시간 사용하면 팔이 피로해지는 문제도 있었다.

## 개선 방향

- 사용자 손 크기에 맞춘 클릭 임계값 자동 보정
- 손을 크게 움직이지 않아도 되는 상대 좌표 모드
- 제스처 설정 화면과 감도 조절 기능
- 두 손을 활용한 확대·축소와 스크롤
- 접근성 테스트를 통한 제스처 단순화

## 회고

이 프로젝트를 통해 AI 모델을 호출하는 것만으로 좋은 사용자 경험이 만들어지지 않는다는 점을 배웠다. 좌표 보정, 상태 관리, 지연 시간, 안전한 중지 방법처럼 모델 바깥의 설계가 실제 조작감에 큰 영향을 주었다.
