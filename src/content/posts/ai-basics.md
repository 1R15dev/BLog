# AI 기초: 인공지능은 어떻게 학습하고 판단할까?

인공지능(AI)은 사람이 지시한 모든 규칙을 그대로 따라가는 프로그램을 넘어, 데이터에서 패턴을 찾아 예측하거나 새로운 결과를 만드는 기술을 말한다. 그러나 AI가 사람처럼 모든 것을 이해하는 것은 아니다. 주어진 목표와 데이터의 범위 안에서 수학적으로 가능성이 높은 결과를 계산한다.

## 1. AI, 머신러닝, 딥러닝의 차이

세 용어는 포함 관계로 이해하면 쉽다.

```text
인공지능(AI)
└─ 머신러닝(Machine Learning)
   └─ 딥러닝(Deep Learning)
```

- **인공지능**: 지능적인 행동을 수행하는 기술 전체다.
- **머신러닝**: 데이터에서 규칙을 학습하는 AI 방식이다.
- **딥러닝**: 여러 층의 인공 신경망을 사용하는 머신러닝 방식이다.
- **생성형 AI**: 학습한 패턴을 바탕으로 글, 이미지, 음성, 코드 등의 새 콘텐츠를 생성한다.

## 2. 규칙 기반 프로그램과 머신러닝

일반 프로그램은 사람이 규칙과 데이터를 넣으면 결과를 출력한다.

```text
규칙 + 데이터 → 결과
```

머신러닝은 데이터와 정답 예시를 통해 규칙에 해당하는 모델을 만든다.

```text
데이터 + 정답 → 학습 → 모델
새 데이터 + 모델 → 예측
```

예를 들어 스팸 메일 분류 모델은 많은 정상 메일과 스팸 메일을 보고, 특정 단어와 문장 구조가 스팸일 가능성과 어떤 관계가 있는지 학습한다.

## 3. AI 학습의 기본 과정

### 1) 문제 정의

무엇을 입력받아 어떤 결과를 낼지 정한다. "좋은 AI를 만든다"보다 "센서 데이터를 이용해 장비의 고장 여부를 분류한다"처럼 구체적이어야 한다.

### 2) 데이터 수집과 정리

모델이 배울 사례를 모은다. 빠진 값, 잘못된 값, 중복된 값을 정리하고 필요한 경우 정답 라벨을 붙인다.

### 3) 학습·검증·테스트 데이터 분리

- **학습 데이터**: 모델이 패턴을 배우는 데 사용한다.
- **검증 데이터**: 모델 설정을 조정하고 성능을 비교한다.
- **테스트 데이터**: 최종 모델이 새로운 데이터에서도 잘 작동하는지 확인한다.

시험 문제를 미리 보고 외우면 실력을 제대로 평가할 수 없는 것처럼, 테스트 데이터가 학습에 섞이지 않도록 주의해야 한다.

### 4) 모델 학습

모델이 예측한 값과 실제 정답의 차이를 **손실(loss)**로 계산한다. 학습 알고리즘은 손실을 줄이는 방향으로 모델 내부의 숫자인 **가중치(weight)**를 조금씩 조정한다.

### 5) 평가와 개선

정확도뿐 아니라 문제에 알맞은 평가 지표를 선택한다. 데이터가 불균형하거나 특정 집단에서 오류가 커지지 않는지도 확인한다.

## 4. 지도학습, 비지도학습, 강화학습

### 지도학습

정답이 있는 데이터로 학습한다.

- 분류: 사진 속 동물이 고양이인지 강아지인지 판단
- 회귀: 면적과 위치를 이용해 집값 예측

### 비지도학습

정답 없이 데이터 자체의 구조를 찾는다.

- 군집화: 비슷한 구매 행동을 가진 고객 그룹 찾기
- 차원 축소: 복잡한 데이터의 핵심 특징만 압축하기

### 강화학습

에이전트가 환경에서 행동하고 보상을 받으며 장기적인 보상을 키우는 방법을 학습한다. 게임 플레이, 로봇 제어, 경로 최적화 등에 활용된다.

## 5. 인공 신경망과 딥러닝

인공 신경망은 입력값에 가중치를 곱하고 더한 뒤, 활성화 함수를 거쳐 다음 층으로 값을 전달한다.

```text
입력층 → 은닉층 → 은닉층 → 출력층
```

층이 깊어질수록 단순한 특징을 조합해 더 복잡한 특징을 표현할 수 있다. 이미지 모델은 초기 층에서 선과 모서리를, 뒤쪽 층에서 눈·바퀴·얼굴 같은 복잡한 형태를 학습할 수 있다.

## 6. 생성형 AI와 언어 모델

대규모 언어 모델(LLM)은 많은 텍스트에서 단어와 문장이 이어지는 패턴을 학습한다. 입력된 문맥을 바탕으로 다음에 올 가능성이 높은 토큰을 반복해서 예측해 문장을 생성한다.

생성형 AI는 다음 작업에 활용할 수 있다.

- 글의 초안과 요약 만들기
- 아이디어 탐색과 질문 답변
- 코드 작성과 오류 설명
- 이미지·음악·음성 생성
- 자료의 분류와 구조화

하지만 자연스러운 답이 항상 사실인 것은 아니다. 존재하지 않는 정보를 그럴듯하게 만드는 **환각(hallucination)**이 발생할 수 있으므로 중요한 정보는 원본 자료를 통해 확인해야 한다.

## 7. 자주 쓰는 AI 용어

| 용어 | 의미 |
| --- | --- |
| 특성(Feature) | 예측에 사용하는 입력 정보 |
| 라벨(Label) | 모델이 맞혀야 하는 정답 |
| 모델(Model) | 데이터에서 학습된 계산 구조 |
| 학습(Training) | 모델의 가중치를 조정하는 과정 |
| 추론(Inference) | 학습된 모델로 새 결과를 만드는 과정 |
| 에포크(Epoch) | 전체 학습 데이터를 한 번 확인한 횟수 |
| 과적합(Overfitting) | 학습 데이터를 외워 새 데이터에서 성능이 떨어지는 현상 |

## 8. 정확도만 높으면 좋은 AI일까?

항상 그렇지는 않다. 환자 100명 중 1명만 질병이 있는 상황에서 모두 정상이라고 예측해도 정확도는 99%다. 하지만 질병을 한 명도 찾지 못하므로 실제로는 쓸모가 없다.

그래서 문제에 따라 다음 지표를 함께 본다.

- **정밀도(Precision)**: 양성이라고 예측한 것 중 실제 양성의 비율
- **재현율(Recall)**: 실제 양성 중 모델이 찾아낸 비율
- **F1 점수**: 정밀도와 재현율의 균형

## 9. 책임 있게 AI 사용하기

- 개인정보와 민감한 자료를 함부로 입력하지 않는다.
- AI 결과의 출처와 사실 여부를 확인한다.
- 데이터에 포함된 편향이 결과에 반복될 수 있음을 기억한다.
- AI가 만든 결과임을 밝혀야 하는 상황을 구분한다.
- 사람에게 큰 영향을 주는 결정은 인간의 검토 없이 자동화하지 않는다.

## 10. 입문 실습 아이디어

1. 숫자 데이터를 이용한 간단한 선형 회귀
2. 붓꽃 데이터를 이용한 품종 분류
3. 카메라 이미지로 두 가지 물체 구분하기
4. Arduino 센서 데이터를 수집해 상태 분류하기
5. 같은 질문의 프롬프트를 바꾸며 생성 결과 비교하기

## 마무리

AI를 공부할 때 가장 중요한 질문은 "어떤 모델을 쓸까?"보다 **어떤 문제를 풀고 있으며, 어떤 데이터로 판단하고, 결과를 어떻게 검증할 것인가?**이다. 작은 데이터로 직접 학습과 평가 과정을 경험한 뒤 복잡한 모델로 확장해 보자.
