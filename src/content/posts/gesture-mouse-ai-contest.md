# 손동작으로 조작하는 AI 가상 마우스

## 고교 AI 활용대회

웹캠이 손의 위치와 모양을 인식하고, 사용자의 손동작을 마우스 이동과 클릭으로 변환하는 가상 마우스 시스템을 제작했다. 별도의 센서나 장갑 없이 일반 카메라만 사용한다는 점이 핵심이다.

## 문제와 목표

일반 마우스는 평평한 공간이 필요하고 손으로 직접 잡아야 한다. 발표 중 멀리서 화면을 제어하거나, 마우스를 사용하기 어려운 상황에서는 다른 입력 방법이 필요하다.

프로젝트의 목표는 다음과 같다.

- 카메라 한 대만으로 손을 실시간 인식한다.
- 손가락 위치를 화면 좌표로 변환한다.
- 직관적인 제스처로 이동, 클릭, 드래그를 수행한다.
- 작은 손 떨림으로 커서가 흔들리는 현상을 줄인다.

## 시스템 흐름

```text
웹캠 영상 입력
→ 손 랜드마크 21개 검출
→ 손가락 상태와 거리 계산
→ 제스처 분류
→ 화면 좌표로 변환
→ 운영체제 마우스 이벤트 실행
```

## 사용한 기술

- **Python**: 전체 프로그램 작성
- **OpenCV**: 카메라 영상 입력과 화면 표시
- **MediaPipe Hands**: 손과 21개 관절 좌표 검출
- **PyAutoGUI**: 커서 이동과 클릭 이벤트 실행
- **이동 평균 필터**: 커서 떨림 완화

## 제스처 설계

| 손동작 | 기능 |
| --- | --- |
| 검지만 펴기 | 커서 이동 |
| 검지와 엄지 붙이기 | 왼쪽 클릭 |
| 중지와 엄지 붙이기 | 오른쪽 클릭 |
| 검지와 엄지를 붙인 채 이동 | 드래그 |
| 손바닥 펼치기 | 입력 일시 정지 |

## 핵심 구현 개념

검지 끝의 카메라 좌표 `(x, y)`를 화면 해상도에 맞게 변환한다.

```python
screen_x = camera_x / camera_width * screen_width
screen_y = camera_y / camera_height * screen_height
```

실제로는 손이 화면 끝까지 이동하지 않아도 커서가 전체 화면에 도달하도록 카메라 내부에 가상의 작동 영역을 설정했다. 최근 여러 프레임의 좌표를 평균 내어 커서 이동도 부드럽게 만들었다.

## 클릭 판정

엄지 끝과 검지 끝 사이의 유클리드 거리를 구하고, 일정 값보다 작아지면 클릭으로 판단한다.

```python
distance = ((thumb_x - index_x) ** 2 + (thumb_y - index_y) ** 2) ** 0.5

if distance < click_threshold:
    click()
```

손이 붙어 있는 동안 클릭이 계속 발생하지 않도록 한 번 클릭한 뒤 손가락이 다시 벌어질 때까지 기다리는 상태 제어를 추가했다.

## 해결한 문제

- **커서 떨림**: 좌표 보간과 이동 평균 적용
- **연속 클릭**: 클릭 잠금 상태와 대기 시간 적용
- **좌우 반전**: 카메라 영상을 거울처럼 반전
- **잘못된 제스처**: 손가락 각도와 거리 조건을 함께 사용
- **화면 이탈**: 좌표를 화면 범위 안으로 제한

## 기대 효과와 확장

발표 화면 제어, 비접촉 키오스크, 접근성 입력 장치, 간단한 게임 조작 등에 활용할 수 있다. 이후에는 스크롤, 확대·축소, 사용자별 제스처 학습과 같은 기능을 추가할 수 있다.
