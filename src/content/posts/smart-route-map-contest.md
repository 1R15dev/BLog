# 실시간 버스·교통 정보를 반영한 최적 경로 지도 앱

## 세명컴고 소프트웨어 아이디어 경진대회

기존 길찾기는 가장 빠른 경로를 안내하지만, 버스가 정류장에 도착하기까지의 대기 시간이나 도로의 실시간 정체가 충분히 반영되지 않으면 실제 도착 시간과 차이가 생긴다. 이를 해결하기 위해 **버스 도착 정보, 환승 대기, 도로 정체를 하나의 비용으로 계산하는 지도 앱**을 기획했다.

## 문제 정의

- 지도에 표시된 이동 시간과 실제 이동 시간이 다를 때가 있다.
- 정류장까지 빨리 도착해도 버스 대기 시간이 길면 전체 시간은 늘어난다.
- 환승 횟수가 많으면 지연 가능성과 이동 피로도가 커진다.
- 사용자는 가장 빠른 길 외에도 걷기 최소, 환승 최소 같은 선택이 필요하다.

## 핵심 기능

1. 출발지와 목적지 검색
2. 실시간 버스 도착 예정 시간 반영
3. 도로 구간별 정체 수준 반영
4. 도보, 대기, 탑승, 환승 시간을 합산
5. 여러 후보 경로의 예상 도착 시각 비교
6. 빠른 경로·편한 경로·안정적인 경로 선택

## 경로 점수 계산

단순 거리 대신 사용자가 실제로 소비할 시간을 기준으로 경로의 비용을 계산한다.

```text
총 예상 시간
= 정류장까지 걷는 시간
+ 버스 대기 시간
+ 교통 정체가 반영된 탑승 시간
+ 환승 이동과 추가 대기 시간
```

사용자 설정에 따라 가중치를 바꿀 수도 있다.

```text
경로 점수
= 총 소요 시간 × 시간 가중치
+ 도보 거리 × 도보 가중치
+ 환승 횟수 × 환승 가중치
+ 지연 위험도 × 안정성 가중치
```

## 데이터 구성

- 정류장 위치와 버스 노선 데이터
- 버스 위치 또는 도착 정보 API
- 도로 구간별 실시간 교통 속도
- 보행자 도로와 횡단보도 정보
- 시간대별 평균 지연 이력

실시간 정보가 일시적으로 제공되지 않을 때는 같은 요일과 시간대의 평균값을 사용해 경로 안내가 중단되지 않도록 한다.

## 경로 탐색 방식

지도와 대중교통망을 노드와 간선으로 표현한다.

- **노드**: 교차로, 정류장, 출발지, 목적지
- **간선**: 도보 구간, 버스 이동 구간, 환승 구간
- **가중치**: 해당 구간을 통과하는 예상 시간과 불편 비용

Dijkstra 또는 A* 알고리즘으로 비용이 가장 낮은 경로를 찾고, 상위 후보 여러 개를 사용자에게 보여준다.

## 화면 구성

### 검색 화면

출발지와 목적지를 입력하고 `최단 시간`, `환승 최소`, `도보 최소` 모드를 선택한다.

### 결과 화면

각 경로 카드에 다음 정보를 함께 표시한다.

- 예상 도착 시각
- 버스 도착까지 남은 시간
- 총 도보 거리와 환승 횟수
- 정체가 심한 구간
- 지연 가능성을 나타내는 신뢰도

### 이동 중 화면

버스 도착 정보나 정체가 크게 변하면 기존 경로와 새 경로를 비교해 재탐색을 제안한다. 사용자가 원하지 않으면 현재 경로를 그대로 유지할 수 있다.

## 차별점

이 앱은 지도상 최단 거리만 찾는 것이 아니라 **지금 출발했을 때 실제로 가장 빨리 도착할 가능성이 높은 경로**를 찾는 데 집중한다. 예상 시간의 구성 요소를 사용자에게 보여줘 왜 해당 경로가 선택됐는지도 설명한다.

## 기대 효과와 확장

- 버스 대기와 환승 실패로 인한 시간 낭비 감소
- 교통약자를 위한 계단 회피·도보 최소 옵션 제공
- 학교 통학과 지역 대중교통 이용 편의 향상
- 향후 지하철, 공유 자전거, 전동 킥보드까지 통합 가능

## 개발 단계

1. 한 지역의 정류장과 노선 데이터로 기본 지도 제작
2. 정적 시간표를 이용한 경로 탐색 구현
3. 버스 도착 API와 교통 정보 연결
4. 경로별 예상 시간 비교 화면 제작
5. 실제 이동 결과와 예측값을 비교해 가중치 보정

이 아이디어는 경로 알고리즘과 공공데이터를 결합해 일상에서 바로 체감할 수 있는 문제를 해결하는 소프트웨어를 목표로 한다.
